# SLSEleven

`SLSEleven` — десктопное JavaFX-приложение для ведения учебного календаря, ручного управления занятиями и автоматического распределения часов из пула по правилам.

Проект ориентирован на локальную работу с данными в SQLite (`~/.slseleven/lessons.db`) без внешнего сервера.

## Что умеет приложение

- вести расписание по датам в календаре;
- поддерживать несколько календарей и иерархии директорий;
- хранить пул нераспределённых часов (авторасписание);
- автоматически создавать занятия из пула с учётом ограничений;
- задавать правила по предметам (дни, эксклюзивность, конфликты, лимиты, подрядные часы, фиксированный кабинет);
- управлять преподавателями, кабинетами и нарядами;
- сохранять историю снимков состояния и восстанавливаться из неё;
- импортировать/экспортировать данные (TSV/CSV/XLSX);
- формировать печатные макеты календаря (PNG/Excel A4).

## Требования

### Для запуска и разработки

- JDK 11+
- Maven 3.9+ (или Maven Wrapper `./mvnw`)

### Для упаковки инсталляторов

- JDK 17+ с `jpackage`

## Быстрый старт

```bash
./mvnw clean javafx:run
```

После первого запуска автоматически создаётся каталог данных:

- `~/.slseleven/`
- файл БД: `~/.slseleven/lessons.db`

## Полезные команды

### Тесты

```bash
./mvnw test
```

### Сборка артефактов

```bash
./mvnw clean package
```

### Пакетирование под платформы

- macOS Intel:
```bash
./mvnw clean package -Pmac-x64
```
- macOS Apple Silicon:
```bash
./mvnw clean package -Pmac-arm
```
- Windows:
```bash
./mvnw clean package -Pwindows
```

Готовые инсталляторы создаются в `target/installer/`.

## Как пользоваться

Короткий поток работы:

1. Создайте/выберите календарь.
2. Настройте дневные лимиты часов в окне «Авторасписание».
3. Заполните пул часов (вручную или импортом).
4. При необходимости задайте правила предметов, преподавателей и кабинеты.
5. Запустите «Сформировать расписание».
6. Проверьте результат в календаре и в окне «Все занятия».

## Форматы импорта/экспорта

Поддерживаются:

- `TSV` (табуляции)
- `CSV` (разделители `;` или `,`)
- `XLSX`

Примеры файлов в репозитории:

- `lesson_import_sample.xlsx`
- `test-data/lessons_test.tsv`
- `test-data/schedule_pool_test.tsv`

## Резервное копирование

Для бэкапа достаточно копировать файл:

- `~/.slseleven/lessons.db`

Для восстановления замените файл БД на резервную копию при закрытом приложении.
