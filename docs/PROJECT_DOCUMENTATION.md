# Полная документация проекта SLSEleven

## 1. Назначение проекта
`SLSEleven` — десктопное JavaFX-приложение для ведения календаря занятий и автоматического распределения учебных часов.

Ключевые возможности:
- ручное управление занятиями (создание, редактирование, удаление, архив);
- автораспределение занятий из пула `schedule_items` по правилам;
- ограничения по дням/предметам/преподавателям/кабинетам;
- история снимков состояния расписания с восстановлением;
- работа с несколькими календарями.

## 2. Технологический стек
- Язык: Java 11+ (`maven.compiler.release=11`)
- UI: JavaFX (`javafx-controls`, `javafx-fxml`)
- БД: SQLite (`org.xerial:sqlite-jdbc`)
- Импорт/экспорт: Apache POI (`poi-ooxml`)
- Сборка: Maven
- Тесты: JUnit 5

## 3. Архитектура
Проект организован слоями:

1. `domain/model`
Сущности: `Lesson`, `ScheduleItem`, `SubjectScheduleRule`, `InstructorProfile`, `RoomProfile`, `AppCalendar`, `ScheduleHistorySnapshot`.

2. `domain/repository`
Контракты доступа к данным: `LessonRepository`, `ScheduleItemRepository`, `ScheduleSettingsRepository`, `ScheduleHistoryRepository`.

3. `infrastructure/persistence/sqlite`
SQLite-реализации репозиториев.

4. `usecase`
Бизнес-логика: `LessonUseCase`, `ScheduleUseCase`, `AutoScheduleResult`.

5. `controller`
JavaFX-контроллеры экранов (`CalendarController`, `LessonsListController`, `SchedulePlannerController`, диалоги).

6. `ui`, `util`
UI-утилиты и парсинг/форматирование данных.

## 4. Основные потоки данных

### 4.1 Ручная работа с занятиями
1. Пользователь открывает экран/диалог.
2. Контроллер валидирует ввод.
3. Вызов use-case (`LessonUseCase`/`ScheduleUseCase`).
4. Репозиторий сохраняет изменения в SQLite.
5. UI обновляет представление.

### 4.2 Автораспределение
1. `ScheduleUseCase.autoSchedule(startDate, endDate)` читает пул `schedule_items`.
2. Для каждого дня учитываются:
- лимит часов дня;
- уже занятые слоты;
- правила предметов;
- доступность преподавателей;
- ограничения по соседству и по одному дню.
3. Создаются `Lesson` с флагом `autoScheduled=true`.
4. Из пула списываются использованные часы.
5. Возвращается `AutoScheduleResult` с итогами и остатками.

## 5. Алгоритм автоназначения (текущая версия)
В `ScheduleUseCase` реализованы:
- ротационный старт выбора кандидатов (`round-robin`), чтобы не выбирать всегда первый предмет;
- приоритет смены предмета (избегать одинаковых подряд);
- мягкое ограничение серий одного предмета: стараться не держать блок более ~2 часов подряд, если есть альтернатива;
- fallback на допустимого кандидата, чтобы планирование не зависало;
- поддержка `consecutive_hours`, ограничений по дням, фиксированным кабинетам, конфликтам по соседним слотам и в пределах дня.

## 6. Структура БД (SQLite)
Инициализируется в `SchemaInitializer`.

Таблицы:
- `calendars` — календари и директории;
- `app_settings` — системные настройки (включая активный календарь);
- `lessons` — фактические занятия в календаре;
- `schedule_items` — пул нераспределённых часов;
- `schedule_settings` — лимиты часов по дням;
- `schedule_subject_rules` — правила предметов;
- `instructors` — преподаватели;
- `rooms` — кабинеты;
- `instructor_duties` — дежурства/ограничения преподавателей;
- `schedule_history` — снимки состояния расписания.

Особенности миграции:
- безопасные `ALTER TABLE` (добавление колонок при необходимости);
- нормализация таблиц `schedule_settings`, `schedule_subject_rules`, `calendars` через пересоздание;
- заполнение базовых дефолтов (`default` календарь, лимиты по дням).

## 7. Ключевые модули и ответственность

### `HelloApplication`
- старт приложения;
- инициализация БД и репозиториев;
- создание use-case;
- загрузка главного FXML и внедрение зависимостей.

### `ScheduleUseCase`
- управление пулом распределения;
- авто- и перераспределение;
- возврат авто/архивных занятий в пул;
- история снимков.

### `LessonUseCase`
- CRUD активных/архивных занятий;
- фильтрация по датам и календарям;
- массовые операции архивации/удаления авто-занятий.

## 8. UI-экраны
- `calendar-view.fxml` + `CalendarController`: главный календарь, текущий статус, навигация.
- `lessons-list.fxml` + `LessonsListController`: таблица занятий, импорт/экспорт, архив.
- `schedule-planner.fxml` + `SchedulePlannerController`: пул часов, правила, запуск автоназначения.
- `lesson-dialog.fxml`, `schedule-item-dialog.fxml`: диалоговые формы.

