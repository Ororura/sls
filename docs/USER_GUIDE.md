# Руководство пользователя SLSEleven

## 1. Назначение

`SLSEleven` — локальное приложение для планирования учебных занятий.

В приложении есть два основных контура работы:

- **календарь занятий** (фактические занятия по датам);
- **авторасписание** (пул нераспределённых часов + правила, по которым система заполняет календарь автоматически).

Данные хранятся локально в SQLite, без внешнего сервера.

## 2. Первый запуск

1. Запустите приложение.
2. При первом запуске автоматически создаются:
   - папка `~/.slseleven/`
   - база данных `~/.slseleven/lessons.db`
3. Откроется главный экран календаря.

Если файл БД уже существует, приложение продолжит работу с ним.

## 3. Основные понятия

- **Календарь**: отдельный набор данных (занятия, пул, настройки, правила, преподаватели, кабинеты, история).
- **Директория календаря**: логическая группировка календарей (например: `2 бат/2 рота/ОВП`).
- **Занятие**: запись в календаре (дата, время, предмет, тема, кабинет и т.д.).
- **Пул авторасписания**: список часов, которые нужно распределить по датам.
- **Авто-занятие**: занятие, созданное кнопкой «Сформировать расписание».
- **Архивное занятие**: прошедшее занятие (автоматически помечается архивным).

## 4. Экран «Календарь»

На главном экране доступны:

- переход между месяцами;
- возврат к текущему месяцу;
- просмотр занятий по выбранному дню;
- быстрый переход в «Авторасписание» и «Все занятия»;
- управление календарями и директориями;
- экспорт печатного макета (PNG/Excel);
- статус «текущее/следующее занятие» в шапке.

### 4.1 Работа с днями

- **ЛКМ по дню**: открыть список занятий на эту дату справа.
- **ПКМ по дню**: открыть форму добавления нового занятия на выбранную дату.

### 4.2 Карточки занятий справа

Для каждого занятия доступны:

- просмотр деталей;
- редактирование;
- удаление.

Визуально отмечаются:

- текущее занятие;
- прошедшее занятие.

### 4.3 Управление календарями

В верхней панели:

- **Новый**: создать календарь;
- **Папка**: переместить календарь в директорию;
- **Переименовать**: изменить имя календаря;
- **Удалить**: удалить календарь и все его данные.

Важно:

- нельзя удалить единственный календарь;
- в режиме **«Все календари»** просмотр доступен, но действия редактирования ограничены (нужно выбрать конкретный календарь).

### 4.4 Экспорт печатной формы

- **Печать A4 (PNG)**:
  - можно выбрать все дни месяца или только часть дней;
  - при выборе части дней включается компактный режим.
- **Печать A4 (Excel)**:
  - формируется лист с календарной сеткой месяца и занятиями.

## 5. Экран «Все занятия»

Экран предназначен для ручного управления занятиями и обмена данными.

### 5.1 Операции

- **Добавить**: создать занятие вручную.
- **Удалить**: удалить выбранные записи.
- **Удалить все**: очистить все активные занятия текущего календаря (двойное подтверждение).
- **Обновить**: перезагрузить список.
- **Поиск**: фильтрация по предмету, теме, занятию, месту, преподавателю.

### 5.2 Архив

Кнопка **«Архив»** показывает:

- завершённые темы;
- незавершённые темы;
- список архивных занятий.

Архив формируется автоматически: прошедшие по дате занятия помечаются архивными.

### 5.3 Возврат авто-занятий в пул

- **Вернуть в пул**: возвращает выбранное авто-занятие в пул авторасписания.
- **Вернуть все в пул**: возвращает все авто-занятия текущего календаря.

### 5.4 Импорт/экспорт

- Импорт текстом (`TSV/CSV`) из диалога.
- Импорт `XLSX`.
- Экспорт текстом (`TSV` или `CSV`).
- Экспорт `XLSX`.
- Отчёт по неделям (`XLSX`).

## 6. Экран «Авторасписание»

Здесь формируется пул и выполняется автоматическое распределение.

### 6.1 Пул часов

Каждая строка пула содержит:

- предмет;
- тему;
- занятие;
- место;
- преподавателя;
- часы всего;
- часы подряд (на уровне предмета).

Операции:

- добавить / редактировать / удалить строку;
- удалить всё;
- поиск;
- импорт/экспорт (`TSV/CSV/XLSX`).

### 6.2 Настройки распределения

Внизу окна:

- дата начала;
- дата окончания (можно оставить пустой, тогда без верхней границы);
- лимиты часов по дням недели (Пн–Вс).
- временные слоты занятий через кнопку **«Слоты»**.

В окне слотов каждая строка задаёт время начала занятия в формате `ЧЧ:ММ`.

### 6.3 Правила предметов

Кнопка **«Правила предметов»** позволяет задать ограничения:

- разрешённые дни;
- эксклюзивные дни;
- часы подряд;
- максимум занятий этого предмета в день;
- фиксированный кабинет;
- запрет ставить подряд с выбранными предметами;
- запрет ставить в один день с выбранными предметами.

Если правило предмета эквивалентно значениям по умолчанию, оно не сохраняется как отдельная запись.

### 6.4 Преподаватели

Кнопка **«Преподаватели»**:

- добавить;
- переименовать;
- удалить;
- настроить рабочие дни.

### 6.5 Кабинеты

Кнопка **«Кабинеты»**:

- добавить;
- переименовать;
- удалить.

### 6.6 Наряды преподавателей

Кнопка **«Наряды»**:

- выбрать преподавателя;
- добавить/удалить даты нарядов.

Наряды учитываются алгоритмом распределения.

### 6.7 История

Кнопка **«История»**:

- выбор ранее сохранённого снимка;
- восстановление состояния занятий и пула на момент снимка.

### 6.8 Архив в пул

Кнопка **«Архив в пул»** переносит архивные занятия обратно в пул с агрегированием часов.

### 6.9 Запуск распределения

- **Сформировать расписание**: обычный запуск автоназначения.
- **Проверить**: предварительный расчёт без создания занятий и без изменения пула.
- **Перераспределить**: вернуть авто-занятия выбранного диапазона в пул и назначить заново.

Перед запуском создаётся снимок истории (если есть данные).

## 7. Как работает автораспределение (практически)

Алгоритм размещает часы по слотам календаря. По умолчанию используются:

- `09:00`, `09:50`, `10:50`, `11:40`, `12:40`, `13:30`, `16:00`, `16:50`.

Слоты можно изменить в окне **«Авторасписание» → «Слоты»**.

Учитываются:

- лимиты часов по дням недели;
- уже существующие занятия в эти даты;
- правила предметов (дни, конфликты, лимиты, подрядность);
- доступность преподавателей и их наряды;
- наличие кабинетов и фиксированные кабинеты.

Поведение по приоритетам:

- старается чередовать предметы;
- старается не делать длинные моносерии, если есть альтернатива;
- при невозможности идеального выбора использует допустимый fallback,
  чтобы продолжить планирование.

Результат:

- создаются авто-занятия в календаре;
- использованные часы вычитаются из пула;
- показывается остаток нераспределённых часов;
- для остатка показываются возможные причины: нехватка слотов, запрет дня недели, конфликт предметов, дневной лимит, отсутствующий кабинет или недоступный преподаватель.

## 8. Форматы импорта

### 8.1 Импорт занятий (экран «Все занятия»)

Поддерживается:

- `TSV`
- `CSV` (`;` или `,`)
- `XLSX`

Обязательные поля:

- время;
- предмет;
- тема;
- место;
- преподаватель.

Необязательные:

- дата (если пусто, используется текущая дата);
- занятие (если пусто, подставляется значение поля «Тема»).

Пример заголовков:

```text
Дата	Время	Предмет	Тема	Занятие	Место	Преподаватель
```

### 8.2 Импорт пула (экран «Авторасписание»)

Поддерживается:

- `TSV`
- `CSV` (`;` или `,`)
- `XLSX`

Обязательные поля:

- предмет;
- тема;
- часы.

Необязательные:

- занятие (если пусто, подставляется значение поля «Тема»);
- место;
- преподаватель.

Если для предмета уже есть правило с «часами подряд», импорт подставит это значение.

Пример заголовков:

```text
Предмет	Тема	Занятие	Место	Преподаватель	Часы
```

### 8.3 Кодировки

При загрузке текстовых файлов используется:

1. UTF-8
2. fallback на Windows-1251 (если обнаружены битые символы)

## 9. Экспорт

### 9.1 Список занятий

- текстовый экспорт (`TSV` или `CSV`);
- экспорт в `XLSX`;
- быстрый экспорт в буфер обмена (`TSV`);
- недельный отчёт в `XLSX`.

### 9.2 Пул авторасписания

- экспорт `XLSX`;
- быстрый экспорт в буфер (`TSV`).

### 9.3 Календарь

- печатный `PNG A4`;
- печатный `Excel A4`.

## 10. Частые проблемы и решения

### 10.1 Автораспределение не создаёт занятия

Проверьте:

- пул не пуст;
- есть положительные лимиты часов хотя бы в один день;
- дата начала задана;
- правила предметов не запрещают все варианты;
- есть доступные преподаватели/кабинеты для выбранных правил.

### 10.2 Остались нераспределённые часы

Причины обычно такие:

- узкий диапазон дат;
- маленькие дневные лимиты;
- слишком жёсткие правила совместимости;
- жёсткая фиксация кабинета, которого нет в списке;
- дефицит доступных преподавателей в нужные дни.

### 10.3 Не получается редактировать в режиме «Все календари»

Это ожидаемое поведение. Для изменения данных выберите конкретный календарь.

### 10.4 Нужно восстановить состояние до неудачного перераспределения

1. Откройте «Авторасписание».
2. Нажмите «История».
3. Выберите снимок, созданный до операции.
4. Подтвердите восстановление.

### 10.5 Нужен полный бэкап

Скопируйте файл `~/.slseleven/lessons.db` при закрытом приложении.

## 11. Рекомендуемый рабочий сценарий

1. Создайте календарь для подразделения/группы.
2. Задайте лимиты часов по дням.
3. Добавьте кабинеты и преподавателей.
4. При необходимости внесите наряды.
5. Заполните пул часов.
6. Настройте правила предметов (только где реально нужно).
7. Запустите «Сформировать расписание».
8. Проверьте календарь и список занятий.
9. При необходимости сделайте «Перераспределить».
10. Перед крупными изменениями используйте историю как точку отката.
