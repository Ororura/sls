# Инструкция пользователя SLSEleven

## 1. Что это за приложение
`SLSEleven` помогает вести расписание занятий:
- календарь занятий по датам;
- список всех занятий;
- авто-распределение учебных часов из пула;
- правила по предметам, преподавателям и кабинетам;
- архив и восстановление состояния.

## 2. Первый запуск
1. Запустите приложение.
2. При старте автоматически создаётся база данных в папке:
`~/.slseleven/lessons.db`
3. Откроется главный экран календаря.

## 3. Основные экраны

### 3.1 Календарь
Позволяет:
- смотреть занятия на выбранный день;
- переключать месяцы;
- открывать список занятий;
- открывать планировщик авторасписания;
- работать с календарями/директориями.

### 3.2 Список занятий
Позволяет:
- добавлять и редактировать занятия;
- удалять занятия;
- архивировать прошедшие;
- импортировать/экспортировать данные.

### 3.3 Планировщик авторасписания
Позволяет:
- вести пул часов (предмет, тема, занятие, часы);
- задавать ограничения по дням недели;
- настраивать правила предметов;
- запускать авто-распределение и перераспределение.

## 4. Как добавить занятие вручную
1. Откройте список занятий.
2. Нажмите «Добавить».
3. Заполните поля:
- дата и время;
- предмет;
- тема;
- название занятия;
- кабинет;
- преподаватель.
4. Сохраните.

## 5. Как использовать автораспределение
1. Откройте «Планировщик авторасписания».
2. Добавьте элементы в пул часов (`schedule items`).
3. Установите лимиты часов по дням недели.
4. При необходимости задайте правила предметов:
- допустимые дни;
- эксклюзивные дни;
- подряд часов;
- фиксированный кабинет;
- ограничения совместимости.
5. Нажмите «Распределить».

Результат:
- занятия создаются в календаре автоматически;
- использованные часы списываются из пула;
- остаток отображается в отчёте.

## 6. Поведение алгоритма распределения
Текущая логика старается:
- не ставить один и тот же предмет подряд, если есть альтернатива;
- чередовать предметы более равномерно;
- ограничивать длинные непрерывные серии одного предмета (ориентир около 2 часов подряд);
- при отсутствии альтернатив всё равно заполнить расписание максимально возможным образом.

## 7. Перераспределение
Если уже есть авто-созданные занятия:
1. Выберите период.
2. Запустите «Перераспределить».
3. Авто-занятия за диапазон (и после конца диапазона для согласованности) вернутся в пул и будут назначены заново.

## 8. Архив
- Прошедшие занятия можно архивировать.
- Архивные занятия можно вернуть в пул.
- Доступен массовый возврат архивных/автораспределённых занятий в пул.

## 9. История и восстановление
- Можно создать снимок состояния расписания.
- Можно восстановить состояние из ранее созданного снимка.

## 10. Импорт/экспорт
- Поддерживается импорт/экспорт табличных данных.
- В проекте есть пример файла импорта: `lesson_import_sample.xlsx`.

## 11. Частые ошибки и решения

### Автораспределение не создаёт занятия
Проверьте:
- что в пуле есть часы;
- что есть дни с положительным лимитом часов;
- что правила предметов не запрещают все дни;
- что доступен хотя бы один преподаватель/кабинет.

### Не хватает слотов
Увеличьте лимиты часов нужных дней или расширьте диапазон распределения.

### Нельзя выбрать «все календари» для некоторых действий
Это ограничение интерфейса: часть операций требует конкретный активный календарь.

## 12. Быстрый чек-лист работы
1. Выберите календарь.
2. Заполните пул часов.
3. Настройте лимиты по дням.
4. Добавьте правила предметов (по необходимости).
5. Запустите автораспределение.
6. Проверьте результат в календаре и списке занятий.

## 13. Где хранятся данные
Локально в SQLite:
- `~/.slseleven/lessons.db`

Рекомендуется периодически копировать этот файл как резервную копию.
